# 交付範圍與後續規劃

系統設計見 [DESIGN.md](DESIGN.md)，技術決策見 [DECISIONS.md](DECISIONS.md)。本機已交付 P0 至 P11（P8 的評估程式已移除），各階段使用可重現的模擬資料。

## 已實作

| 階段 | 交付內容 | 驗收 |
| --- | --- | --- |
| P0 開發環境 | Docker Compose、健康檢查、遷移與品質檢查 | API 可連到 PostgreSQL。GitHub Actions 每次推送都執行程式檢查、遷移檢查與測試，並以建置好的 Docker 映像實際匯入樣本 |
| P1 主資料 | 製程、機台、檢驗項目、料號、批號、批號關係與進出站；主資料初始化工具 | 可從空資料庫遷移並載入主資料，重跑可預覽差異 |
| P2 報表匯入 | 四種 CSV／Excel 來源、正規化、整檔拒絕、來源列欄與重傳判定 | 21 份樣本逐檔核對結果與筆數。數值有衝突時保留原量測 |
| P3 操作與查詢 | 上傳、匯入歷史、Excel 錯誤報告、量測查詢和分頁 | 可從工作頁完成上傳、查詢、退件報告下載及重傳查驗 |
| P4 偵測率評估 | 可重跑的匯入評估腳本 | 驗證檔案判定、錯誤位置、召回率、誤報與自動修正，結果見 [README](../README.md#匯入偵測率) |
| P5 批號追溯 | 批號詳情、上下游追溯、進出站與 Q-time | 可由檢驗紀錄追查原料或生產批，並查詢等待與超時狀態 |
| P6 統計製程管制 | I-MR 管制圖、固定基準、異常規則與批號連結 | 可從已入庫資料產出雙圖，也可用模擬事件重跑漂移與突變驗證 |
| P7 服務層與 MCP | 共用查詢、七個唯讀工具、三項資源、調查範本與稽核 | 官方 MCP 客戶端可透過本機 stdio 呼叫工具，越界與無效查詢會被拒絕 |
| P8 本機調查評估（已移除） | 曾實作根因與證據評分、規則基線及模型工具呼叫 | 本機 8B 模型初步測試時無法穩定完成多步驟的工具呼叫，已移除評估程式，見 [決策紀錄](DECISIONS.md#p8-調查評估) |
| P9 匯入範本 | CSV／XLSX 表頭預覽、欄位建議、草稿與人工核准 | 同一份退件檔案選用核准範本後可重試，成功後重傳仍指向原匯入 |
| P10 固定版面 PDF | 固定文字版面擷取、錯誤報告及整檔入庫 | 預設環境可驗證有效 PDF、格式退件、逐列驗證及重傳 |
| P11 模擬情境管理 | 內建與自訂預設、網頁編輯、JSON 交換、TOML 載入、驗證預覽與隔離生成 | 複製 ABF 並修改參數後可儲存、產生及下載；另驗證無 ABF 固定代碼的資料集可匯入並支援追溯及 SPC |
